# Сессия: Фронтенд и UI

**Владеет:** `src/app/`, `src/ui/`, стили и дизайн-токены

## Зона ответственности

Оболочка приложения и весь интерфейс: от загрузки трека до кнопки экспорта. Дизайн-система, состояние приложения,
хранение проектов.

## Что должно получиться

- **Каркас:** Vite + React + TypeScript, Tailwind + shadcn/ui, Zustand. Тёмная тема по умолчанию
  (инструмент для музыкантов), адаптивность (основное — десктоп).
- **Поток пользователя:** загрузка трека → текст (вставка / LRC / распознать) → синхронизация и правка →
  выбор стиля/пресета → акценты на словах → формат и разрешение → экспорт.
- **Редактор текста и таймлайн:** waveform, слова как блоки (перетаскивание, растягивание),
  подсветка неуверенных слов, режим тап-синхронизации (пробел), клик по слову → выбор эффекта-акцента.
- **Превью:** канвас рендер-движка, плеер (play/pause/scrub), переключение формата на лету.
- **Панели:** слои и параметры визуализаторов, пресеты, настройки экспорта, раздел «Модели»
  (скачанные, размер, удалить, импорт из файла).
- **Проекты:** хранение в IndexedDB/OPFS, экспорт/импорт проекта в файл.
- Предупреждения о совместимости браузера (WebCodecs/WebGPU) по feature-detect.

## Требования

- Высокочастотные данные (аудио-кадры, плейхед) — мимо React-ререндеров.
- UI на русском (английский — позже, тексты сразу через словарь).
- Доступность: фокус, клавиатурные сокращения в редакторе.

## Связи

- Использует API всех модулей; сам их логику не реализует.
- Правки общих типов (`src/shared/`) — через главную сессию.
