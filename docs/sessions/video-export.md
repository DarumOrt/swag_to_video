# Сессия: Экспорт видео

**Владеет:** `src/export/`

## Зона ответственности

Покадровый офлайн-рендер и кодирование готового видео в браузере, без сервера и без Remotion.

## Что должно получиться

- **Пайплайн:** для каждого кадра N — рендер-движок рисует кадр → `VideoFrame` → `VideoEncoder` →
  муксер (**mediabunny**) → файл. Аудио — `AudioEncoder` → тот же муксер. Кадры кодируются потоком,
  в памяти не копятся. Обратное давление (`encodeQueueSize`), прогресс, отмена, оценка оставшегося времени.
- **Форматы:** MP4 (H.264 + AAC) — основной; WebM (VP9 + Opus) — запасной; WebM VP9 с альфой — прозрачный
  оверлей, если браузер поддержит (проверить). ProRes — не делаем.
- **Параметры:** пресеты соотношений (9:16 по умолчанию, 16:9, 1:1, 4:5, свои), 720p–4K, 24/30/60 fps, битрейт,
  аппаратное ускорение.
- **Feature-detect:** `VideoEncoder.isConfigSupported` / `AudioEncoder.isConfigSupported` (AudioEncoder не Baseline),
  выбор лучшего доступного кодека; понятное сообщение, если экспорт невозможен.
- Сохранение результата: скачивание blob, для больших файлов — запись потоком (File System Access / OPFS).

## Требования

- Экспорт в отдельном воркере (OffscreenCanvas), UI не зависает.
- Результат кадр-в-кадр совпадает с превью.
- Длинные треки (5+ минут, 4K) не должны падать по памяти.

## Связи

- **Рендер-движок** — API «отрисуй кадр N в W×H». **Аудио-анализ** — исходный звук.
- **Фронт** — диалог экспорта и прогресс.

## Ориентиры

mediabunny, phase-viz (ExportEngine, фолбэк ffmpeg.wasm), canvas-record, webcut (WebCodecs быстрее ffmpeg.wasm).
ffmpeg.wasm — только как возможный фолбэк, ассеты — локально (не с CDN).
