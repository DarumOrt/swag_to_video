# Сессия: ML-модели и Hugging Face

**Владеет:** `src/ml/`, `scripts/models/`, `models.json`

## Зона ответственности

Всё, что связано с нейросетями в браузере: выбор и подготовка моделей, их хостинг на Hugging Face,
загрузка/кэш в браузере, запуск инференса в воркерах.

## Модели

| Модель                                                                  | Назначение                         | Примечания                                                              |
| ----------------------------------------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------- |
| Whisper small `_timestamped` (ONNX)                                     | Распознавание + пословные таймкоды | transformers.js, `return_timestamps: 'word'`                            |
| Whisper large-v3-turbo (квантованная)                                   | Режим «Максимум», опционально      | Сравнить с v2 — по отзывам v3 хуже на музыке                            |
| HTDemucs (ONNX)                                                         | Выделение вокала / стемы           | onnxruntime-web, WebGPU; STFT/iSTFT — в JS                              |
| Выравниватель, обученный на пении (MMS-300m, напр. Tune Studio aligner) | Точные тайминги слов/слогов        | Позже. CC BY-NC (допустимо). RU — через латинизацию, качество проверить |

## Что должно получиться

- **Скрипт** в `scripts/models/`: скачать нужные ONNX-файлы, посчитать SHA-256, собрать `models.json`,
  залить в публичный HF-репозиторий пользователя. Токен — только из переменной окружения,
  скрипт запускает сам пользователь.
- **Манифест `models.json`:** имя, версия, файлы, размеры, sha256, URL.
- **Загрузчик:** по требованию (не при старте), с подтверждением размера, прогрессом, проверкой хэша,
  кэш в Cache API / OPFS, `navigator.storage.persist()`. Импорт моделей из файла. Удаление из настроек.
- transformers.js настраивается на HF-репозиторий пользователя (`env.remoteHost` / `remotePathTemplate`).
- Инференс в Web Worker, прогресс и отмена.

## Известные риски (из исследования)

- Пословные таймкоды на **WebGPU** в transformers.js исторически ломались; рабочая конфигурация —
  `_timestamped`-модели, `encoder_model: 'fp32'`, `decoder_model_merged: 'q4'`. Есть проекты, где по умолчанию WASM.
  **Проверить прототипом в первую очередь.**
- Галлюцинации Whisper на не-речи — не запускать на участках без вокала, фильтр типовых фраз
  («Продолжение следует…», «Субтитры сделал…»), отсев по уверенности и зацикливанию.
- HTDemucs ~85–170 МБ, нужен COEP; для плавного UI — разбиение на части (пример: htdemucs-web-onnx).
- Работа с HF при включённом COEP — проверить CORS.

## Связи
